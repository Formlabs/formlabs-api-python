# Formlabs SDK

> This is formlabs-sdk v1.0.0-alpha.post1, for PreForm API v1.0.0-alpha (PreForm 3.64.0.663). The SDK is versioned by the API: [every release](https://github.com/Formlabs/formlabs-api-python/releases) is tagged `v<api version>`, or `v<api version>.post<N>` for an SDK-only fix, and [the API v1.0.0-alpha reference](https://developer.formlabs.com/api-reference/v1.0.0-alpha/) stays online after newer ones.

The Formlabs Python SDK provides access to the Formlabs PreForm API for Python applications.

## API Documentation

Documentation for the SDK and PreForm API is available on the [Formlabs Developer Portal](https://developer.formlabs.com).

## Install

Python 3.11 or newer.

```
pip install "formlabs-sdk @ git+https://github.com/Formlabs/formlabs-api-python@v1.0.0-alpha.post1"
```
